# python-everything_is_object

Everything is an object in Python: identity, type, mutable and immutable objects,
and how arguments are passed to functions.

Tasks 0 to 18 and 20 to 28 are short questions, answered in `N-answer.txt` files.
Task 19 is a function.

| File | Description |
|------|-------------|
| 0-answer.txt, 1-answer.txt | Functions to get the type and the identity of an object |
| 2-answer.txt to 5-answer.txt | Do two integer variables point to the same object? |
| 6-answer.txt to 13-answer.txt | `==` versus `is` on strings and lists |
| 14-answer.txt to 18-answer.txt | Aliases and arguments passed to functions |
| 19-copy_list.py | `copy_list(l)`: returns a copy of a list |
| 20-answer.txt to 23-answer.txt | Tuple or not? |
| 24-answer.txt to 26-answer.txt | Identity of equal tuples |
| 27-answer.txt, 28-answer.txt | `a = a + [x]` versus `a += [x]` and the object id |
