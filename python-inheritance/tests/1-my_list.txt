The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class:

    >>> MyList = __import__('1-my_list').MyList

It inherits from list:

    >>> issubclass(MyList, list)
    True

An empty list prints an empty list:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

Elements appended in any order are printed sorted:

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The original list is not modified:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

An already sorted list stays the same:

    >>> my_list = MyList([1, 2, 3])
    >>> my_list.print_sorted()
    [1, 2, 3]

Negative numbers and duplicates are handled:

    >>> my_list = MyList([3, -1, 2, -5, 3, 0])
    >>> my_list.print_sorted()
    [-5, -1, 0, 2, 3, 3]
    >>> print(my_list)
    [3, -1, 2, -5, 3, 0]

A reverse sorted list is sorted ascending:

    >>> my_list = MyList([5, 4, 3, 2, 1])
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

A single element list:

    >>> my_list = MyList([7])
    >>> my_list.print_sorted()
    [7]

It is a real list, with every list method:

    >>> my_list = MyList([2, 1])
    >>> my_list.append(0)
    >>> len(my_list)
    3
    >>> my_list[0]
    2

print_sorted takes no argument:

    >>> my_list.print_sorted(1)  # doctest: +ELLIPSIS
    Traceback (most recent call last):
    ...
    TypeError: ...print_sorted() takes 1 positional argument but 2 were given
