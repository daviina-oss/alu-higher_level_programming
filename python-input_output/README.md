# python-input_output

Reading and writing files, and JSON serialization and deserialization in Python.

| File | Description |
|------|-------------|
| 0-read_file.py | `read_file(filename)`: prints a UTF8 text file to stdout |
| 1-write_file.py | `write_file(filename, text)`: writes (overwrites) a file, returns the characters written |
| 2-append_write.py | `append_write(filename, text)`: appends to a file, returns the characters added |
| 3-to_json_string.py | `to_json_string(my_obj)`: object to JSON string |
| 4-from_json_string.py | `from_json_string(my_str)`: JSON string to object |
| 5-save_to_json_file.py | `save_to_json_file(my_obj, filename)`: writes an object as JSON to a file |
| 6-load_from_json_file.py | `load_from_json_file(filename)`: creates an object from a JSON file |
| 7-add_item.py | Adds all arguments to a list saved in `add_item.json` |
| 8-class_to_json.py | `class_to_json(obj)`: dictionary description of an object |
| 8-my_class.py, 8-my_class_2.py | Example classes given with task 8 |
| 9-student.py | `Student` with `to_json()` |
| 10-student.py | `Student.to_json(attrs=None)` with an attribute filter |
| 11-student.py | `Student` with `reload_from_json()` (serialization and deserialization) |
| 12-pascal_triangle.py | `pascal_triangle(n)`: Pascal's triangle as a list of lists |
