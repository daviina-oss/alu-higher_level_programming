# python-more_data_structures

Sets, dictionaries, list comprehensions and `map` in Python.

| File | Description |
|------|-------------|
| 0-square_matrix_simple.py | Squares every integer of a matrix (new matrix) |
| 1-search_replace.py | Replaces all occurrences of an element in a new list |
| 2-uniq_add.py | Adds all unique integers of a list |
| 3-common_elements.py | Returns the common elements of two sets |
| 4-only_diff_elements.py | Returns the elements present in only one of two sets |
| 5-number_keys.py | Returns the number of keys in a dictionary |
| 6-print_sorted_dictionary.py | Prints a dictionary ordered by key |
| 7-update_dictionary.py | Replaces or adds a key/value in a dictionary |
| 8-simple_delete.py | Deletes a key from a dictionary |
| 9-multiply_by_2.py | Returns a new dictionary with all values doubled |
| 10-best_score.py | Returns the key with the biggest integer value |
| 11-multiply_list_map.py | Multiplies a list by a number using `map` |
| 12-roman_to_int.py | Converts a Roman numeral to an integer |
