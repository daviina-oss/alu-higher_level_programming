# python-more_classes

More on classes and objects: a `Rectangle` class built up in steps.

| File | Description |
|------|-------------|
| 0-rectangle.py | Empty class `Rectangle` |
| 1-rectangle.py | Private `width` and `height` with validated properties |
| 2-rectangle.py | Adds `area()` and `perimeter()` |
| 3-rectangle.py | Adds `__str__` to print the rectangle with `#` |
| 4-rectangle.py | Adds `__repr__` so `eval(repr(r))` recreates the rectangle |
| 5-rectangle.py | Prints `Bye rectangle...` when an instance is deleted |
| 6-rectangle.py | Adds the class attribute `number_of_instances` |
| 7-rectangle.py | Adds the class attribute `print_symbol` |
| 8-rectangle.py | Adds the static method `bigger_or_equal` |
| 9-rectangle.py | Adds the class method `square` |
