# python-import_modules

Importing modules, using `sys.argv`, and making scripts safe to import.

| File | Description |
|------|-------------|
| 0-add.py | Imports `add` from `add_0` and prints 1 + 2 = 3 |
| 1-calculation.py | Uses `add`, `sub`, `mul`, `div` from `calculator_1` |
| 2-args.py | Prints the number of arguments and the list of them |
| 3-infinite_add.py | Prints the sum of all arguments |
| 4-hidden_discovery.py | Prints the names defined by `hidden_4.pyc` (Python 3.8) |
| 5-variable_load.py | Imports and prints the variable `a` from `variable_load_5` |

`add_0.py`, `calculator_1.py` and `variable_load_5.py` are the helper modules given in the tasks.
`hidden_4.pyc` must be downloaded separately and needs Python 3.8.
