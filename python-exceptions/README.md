# python-exceptions

Handling and raising exceptions in Python.

| File | Description |
|------|-------------|
| 0-safe_print_list.py | Prints x elements of a list, safely |
| 1-safe_print_integer.py | Prints an integer with `{:d}`, returns whether it worked |
| 2-safe_print_list_integers.py | Prints the first x elements of a list, integers only |
| 3-safe_print_division.py | Divides two integers and prints the result in `finally` |
| 4-list_division.py | Divides two lists element by element |
| 5-raise_exception.py | Raises a `TypeError` |
| 6-raise_exception_msg.py | Raises a `NameError` with a message |
