# python-classes

Classes and objects in Python, built up step by step around a `Square` class.

| File | Description |
|------|-------------|
| 0-square.py | Empty class `Square` |
| 1-square.py | `Square` with a private `size` |
| 2-square.py | Adds `size` validation (`TypeError` / `ValueError`) |
| 3-square.py | Adds the `area()` method |
| 4-square.py | Adds a `size` property with getter and setter |
| 5-square.py | Adds `my_print()` to print the square with `#` |
| 6-square.py | Adds a validated `position` property used by `my_print()` |
